# KNOWN_ISSUES

- Нет моделей кораллов/морских растений (каталог B/C не скачан) — риф собран из скал Kenney/Poly Haven; материалы coral_* применены позже.
- debug-keystore генерируется на каждый CI-run: переустановка APK требует удаления старого (подпись меняется).
- Godot-редактор в PRoot (эмулятор AArch64) крашится — вся валидация только через GitHub Actions.
- Лёгкое проникновение скал в террейн при scatter (sink 0.2-3 м) — приемлемо для этапа 1, будет переработано с LOD на этапе 6.
- Water-шейдер не имеет подводного искажения (refraction) — этап 3.
- Скорость звука на глубине — линейный кроссфейд, чуть грубовато — этап 5 уточнит образцами.
- Обновление качества «scatter_mult» применяется только при рестарте сцены (пересборка мира) — указано в настройках.
- Черепахи нет (в скачанных ZigZagVibe-моделях GLB отсутствует turtle) — вместо неё манта; донести в каталог при следующей загрузке ассетов (категория A: quaternius turtle? отсутствует).
- Стаи не избегают больших объектов (утёсы MultiMesh) упрощённо — только границы глубины; заметно редко (клавирование bottom есть).
